# Fase 1 - Proyecto Expo y navegacion base

## Que se hizo

- Se creo el esqueleto de `mobile/` con configuracion inicial.
- Se armo un `RootNavigator` con ramas autenticadas y publicas.
- Se dejaron pantallas placeholder para validar la estructura de navegacion.
- Se agrego un `ThemeProvider` y un hook de responsividad para tablet/phone.

## Como se abordo

- Se priorizo la estructura antes que los detalles visuales.
- Se uso un placeholder reutilizable para no multiplicar componentes vacios.
- Se dejo el arbol listo para crecer sin reescribir el shell cuando empiecen las fases de funcionalidad.
